# WebV2 Project Brain

This file is the navigation index for WebV2 project knowledge. It stores no separate project truth.

Read first:
1. `WEBV2_MANUAL.md`
2. Canonical current state from GitHub `main/WEBV2_CURRENT.md`
3. `/api/project-status` and relevant component deployment evidence
4. Relevant owner document only as needed.

- `WEBV2_ROADMAP.md` — where the cleanup is going and phase status.
- `WEBV2_ARCHITECTURE.md` — who owns each responsibility.
- `WEBV2_PLAYBOOKS.md` — proven repeatable procedures.

- `WEBV2_DECISIONS.md` — durable design decisions and rationale.
- `WEBV2_LESSONS.md` — operational lessons from success/failure.
- `WEBV2_CLEANUP.md` — evidence-gated deletion queue.

Registry/D1 `WEBV2_CURRENT.md` remains mirror/history/fallback. `/api/project-status` remains Registry deployment truth. Neither a stale mirror nor a GitHub statement overrides verified deployment reality; real mismatches enter reconciliation mode.

Historical docs are evidence/reference only once their unique knowledge is migrated here. They never override canonical GitHub CURRENT or verified live evidence.
